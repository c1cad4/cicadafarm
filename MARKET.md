# CicadaFarm market

Prices and published stock are configured in assets/market-core.js. Honey uses litres; tea and nuts use kilograms; eggs use individual eggs. Two rental terms share four available hives. Token decimals (6) were checked against GeckoTerminal's included base-token metadata.

Product and cart prices follow the specified GeckoTerminal pool every 30 seconds while the market is visible. Checkout fetches a fresh price and fixes the quoted token amount for five minutes, rounded UP to the smallest token unit with BigInt. A stale/unavailable rate never enables a new checkout. An old signed payment URL cannot be revoked on chain after expiration: the farm must handle late transfers manually. Quotes are stored on the buyer's device and can be reopened after reload.

Payment uses the Solana Pay transfer specification with the CICADAFARM mint, recipient wallet and unique order memo. The locally vendored QR library is qrcodejs 1.0.0 (MIT), https://github.com/davidshimjs/qrcodejs. A compatible mobile wallet can scan the QR. The buyer signs in their wallet; the site never requests a secret key. Browser verification calls Solana mainnet RPC for a FINALIZED transaction. It checks success, the order memo, payment time and net recipient balance increase for the correct mint/decimals. Public RPC can rate-limit requests; buyers can send the signature to the farm for manual verification.

This is a manual fulfilment workflow, NOT a centrally reserved stock system. Published stock is not decremented across browsers. The farm confirms goods availability, shipping, recipient contact details and acceptance in Telegram BEFORE payment; it then records each fulfilled order and updates published stock. The downloadable JSON is a buyer-created document, not an authenticated merchant invoice: never trust its status, items, USD value or token amount without independently checking the actual chain transaction, quote and agreed order. Never fulfil the same transaction twice. Browser storage is not a trusted ledger.

For automatic Telegram notifications and concurrent stock reservations, deploy a server with a database: issue authoritative quotes/order IDs and references, atomically reserve inventory, independently validate finalized transfers, enforce unique transaction signatures, release expired unpaid reservations, and send Telegram notifications using a server-held bot token. Keep Telegram tokens and RPC credentials out of GitHub Pages/frontend code. No bot has been created or connected by this change.

Shipping is quoted separately. Eggs are pickup only. Honey can ship internationally subject to the agreed delivery route. Hive rentals must be confirmed by the farm before payment. No live farm camera service is introduced by this checkout.
